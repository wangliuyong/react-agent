# 发布抖音热点图文

## 适用场景
- 用户要求“发一条抖音图文，内容关于今日热点”
- 需要自动选题、配图并发布

## 标准任务清单
1. **获取抖音热点**
   - 使用工具 `fetch_hot_topics`，指定 `source="douyin"` 获取今日热点列表。
2. **搜索候选热点新闻**
   - 针对多个热门话题，使用 `web_search` 搜索新闻来源页，获取摘要和链接。
3. **选择最优热点**
   - 根据话题热度、可配图性、时效性等评估，确定最终选题（例如影视娱乐类优先）。
4. **配图准备**
   - 尝试使用 `fetch_web_images` 从新闻文章页抓取配图。
   - 若抓取失败，可告知用户提供本地图片或使用备用图源。
5. **填写文案并发布**
   - 调用 `douyin_publish_note`，标题不超过20字，附上选好的图片。

## 工具与参数
- `fetch_hot_topics`：`source` 参数设为 `"douyin"`
- `web_search`：引擎建议 `Bing`，查询关键词为热点标题 + “新闻”
- `fetch_web_images`：目标 URL 为新闻文章页
- `douyin_publish_note`：参数包括 `title`（≤20字）、`images`（图片列表）

## 注意事项 / 常见问题
- 图片抓取可能因网站限制而失败，此时应主动询问用户是否有本地图片或提供备用图片。
- 标题需控制在20字以内，建议直接使用热点名称或精简版本。
- 确保发布前已确认抖音登录状态（工具 `douyin_publish_note` 需要登录）。
