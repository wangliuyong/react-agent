# Remotion 设计系统

> 专业级视频视觉规范，源自 Material Design、Apple HIG 及动态图形设计最佳实践。
> Starter 模板已内置 `src/theme/` 目录，可直接引用预设变量。

## 一、配色系统

### 核心原则
- **三色原则**：主色 + 辅助色 + 强调色，不超过 3 种主色相
- **对比度**：文字与背景对比度 ≥ 4.5:1（WCAG AA 标准）
- **情绪匹配**：
  - 科技/专业 → 蓝色系 + 深色背景
  - 高端/奢华 → 黑金 / 深灰 + 金色点缀
  - 活力/年轻 → 亮色 + 浅色背景
  - 温暖/亲和 → 暖色调（橙/红/米）

### 预设调色板（Starter 内置）

| 主题 | 适用场景 | 背景色 | 主色 |
|------|---------|-------|------|
| `DARK_TECH` | 科技产品、数据可视化、B端演示 | `#0f172a` 深蓝灰 | `#3b82f6` 亮蓝 |
| `LIGHT_MINIMAL` | 教育、生活方式、简约品牌 | `#ffffff` 纯白 | `#2563eb` 深蓝 |
| `PREMIUM_GOLD` | 高端品牌、奢侈品、颁奖 | `#0a0a0a` 纯黑 | `#d4af37` 金色 |

### 渐变背景预设
- `deepOcean`：深海蓝渐变 — 科技、专业
- `sunset`：日落紫蓝 — 氛围感、叙事
- `midnight`：午夜纯黑 — 高端、影院感
- `aurora`：极光青绿 — 创新、未来感

### 避坑指南
❌ 不要用紫色/靛蓝渐变作为默认（AI 生成通病，缺乏品牌辨识度）
❌ 不要在文字后面放复杂背景图（可读性差）
✅ 优先使用单色 + 微妙渐变，胜过多色拼接
✅ 深色主题用 8-12% 透明度的白色描边增加精致感

## 二、排版系统

### 字号层级（1920×1080 基准）

| 层级 | 字号 | 用途 |
|------|------|------|
| Hero | 96px | 主标题、开场大标题 |
| H1 | 72px | 章节标题 |
| H2 | 56px | 二级标题 |
| H3 | 42px | 三级标题 / 卡片标题 |
| Body Lg | 32px | 大号正文 |
| Body | 24px | 标准正文 / 字幕 |
| Caption | 16px | 说明文字、标签 |

### 字重规范
- 标题：600-800（semibold ~ extrabold）
- 正文：400-500（regular ~ medium）
- 强调：加粗 + 主色

### 行高
- 标题：1.1（紧凑有力）
- 正文：1.4-1.6（舒适阅读）

### 文字动画铁则
1. **一屏一信息**：单屏文字不超过 7 个词，不要堆满整句话
2. **停留时间**：文字停留时长 = 正常阅读速度 × 2（给观众消化时间）
3. **入场方式**：
   - 标题：从下方滑入 + 淡入（距离 20-40px）
   - 正文：错落逐字出现（stagger 4-6 帧/字）
   - 数字：计数滚动动画
4. **不要做**：
   ❌ 旋转文字入场（廉价感）
   ❌ 弹性过大的文字缩放
   ❌ 整段文字同时淡入（没有层次感）

## 三、间距与布局

### 8px 网格系统
所有间距为 8 的倍数：8 / 16 / 24 / 40 / 64 / 96px

### 视觉层次构建
1. **单一焦点**：每帧只有一个视觉重心，其余元素退居背景
2. **不对称布局**：左对齐或右对齐比居中更有设计感
3. **留白即设计**：大量空白区域让画面呼吸，不要塞满
4. **边缘对齐**：元素沿画面边缘排列创造视觉张力

### 安全边距
- 横版：左右各留 80-120px 安全边距
- 竖版：上下各留 120-160px（避开状态栏、字幕区）
- 重要内容不要贴边

## 四、动效设计原则

### 动效的三个目的（缺一不可）
1. **Reveal 揭示**：把新信息带入画面（入场、绘制、数字增长）
2. **Focus 聚焦**：引导注意力到当前重点（高亮、脉冲、镜头推进）
3. **Continuity 连续**：连接前后场景（平移、归位过渡）

> 不符合这三条的动效，直接删掉。克制比花哨高级得多。

### 缓动曲线选择
- **入场**：`EASE_DECELERATE`（快开始，慢结束）— 自然
- **退场**：`EASE_ACCELERATE`（慢开始，快结束）— 干脆
- **状态切换**：`EASE_STANDARD` 或 `EASE_APPLE` — 顺滑
- **强调元素**：轻微回弹 `EASE_BOUNCE_IN` — 有活力

### 动画时长参考
- 图标/小元素：15-25 帧（0.5-0.8s @30fps）
- 标题/大元素：30-50 帧（1-1.7s）
- 场景转场：20-40 帧
- 完整页面过渡：60-90 帧

### 错落动画（Stagger）
多个同类元素入场时，每个延迟 4-8 帧：
- 少元素（3-5个）：stagger = 8 帧
- 多元素（10+）：stagger = 4 帧
- 方向：从上到下 / 从左到右 / 从中心向外

## 五、质感加分项

### 电影感颗粒
在最上层叠加一层极淡的噪点纹理（opacity 3-5%），瞬间提升质感，告别"塑料感"。

### 微妙景深
- 前景元素：清晰、饱和度高
- 背景元素：模糊（backdrop-blur）、降低透明度、降低饱和度

### 呼吸感
静态停留的元素加入 ±2-3% 的极慢缩放脉动，画面"活"起来但不干扰注意力。

### 光影层次
- 卡片：微妙的内阴影 + 外发光（深色主题用白色微光）
- 文字：极淡的文字阴影（1-2px 偏移，低透明度）增加立体感

## 六、 Starter 模板内置资源

```
src/
├── theme/
│   ├── colors.ts       # 配色系统 + 渐变预设
│   └── typography.ts   # 字号/字重/间距规范
├── lib/
│   ├── easings.ts      # 缓动曲线 + Spring 预设
│   └── animations.ts   # 常用动画 Hook（淡入/滑入/错落/呼吸）
└── components/
    ├── AnimatedText.tsx  # 逐字错落动画文字
    ├── TitleCard.tsx     # 标题卡片组件
    ├── BarChart.tsx      # 柱状图数据可视化
    └── Subtitles.tsx     # 字幕 + 卡拉OK组件
```

直接 import 使用，无需从零编写。
