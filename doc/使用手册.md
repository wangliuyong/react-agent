# 灵犀 使用手册

跨平台桌面 AI 助手（Electron + React），支持 **智能对话、多渠道发布、流程编排、AI/Remotion 视频、定时任务与消息通知**。  
可在聊天中用 Agent 工具创建定时任务、发布计划与用户规则。  
大模型默认对接 **阿里云百炼（DashScope）** OpenAI 兼容接口；数据全部缓存在本机，不使用数据库。

---

## 1. 环境要求

- Node.js ≥ 20（推荐 `nvm use 20`）
- pnpm ≥ 9
- macOS / Windows / Linux

## 2. 安装与启动

```bash
cd react-agent
pnpm install
pnpm install:browser          # 经 npmmirror 加速下载 Playwright Chromium
pnpm install:remotion-browser # Remotion 渲染依赖（使用 Remotion 视频时需要）
pnpm dev
```

`pnpm install:browser` 默认走国内镜像（npmmirror）。若镜像异常，可用官方源：`pnpm install:browser:official`。

## 3. 配置模型与 API

1. 打开 [阿里云百炼控制台](https://bailian.console.aliyun.com/) 创建 API Key。
2. 启动应用后，侧栏底部进入 **设置** → **模型与 API**。
3. 填写：
  - **DASHSCOPE API Key**
  - **Base URL**（默认 `https://dashscope.aliyuncs.com/compatible-mode/v1`）
  - **模型**（默认 `qwen-plus`，可改为 `qwen-max` / `qwen-turbo` 等）
4. 点击保存。

> 配置数据将会缓存到本地，不会上传云端



### 多模型连接（可选）

在 **设置 → 多模型连接** 中可配置多条 `ModelConnection`（不同供应商、模型、能力标签），并为各 Agent 角色（general、researcher、writer、publisher、scriptwriter 等）指定默认连接。Agent 会按任务内容自动推断能力（vision、reasoning、longContext 等）并路由到合适模型。

### 思考模式

在 **模型与 API** Tab 可开关 **思考模式**。开启后，聊天界面会流式展示模型推理过程（`thinking_delta`），推理结束后再展示工具调用与正式回答。

## 5. 聊天与任务



### 5.1 快捷任务卡

新会话欢迎页展示 8 张快捷任务卡（如「发一条小红书」「一句话生成视频」「设置定时任务」「创建发布计划」「添加一条规则」等），点击即可发送预设指令。可点 **换一批** 轮换更多卡片。

### 5.2 聊天创建配置

在对话中可用自然语言创建本地配置，由 **general** 角色下的 Agent 工具写入磁盘并刷新侧栏列表：


| 工具                                              | 说明                                                       |
| ----------------------------------------------- | -------------------------------------------------------- |
| `query_scheduled_tasks` / `post_scheduled_task` | 定时任务；`post` 新建默认 **未启用**，确认后再设 `enabled: true`           |
| `query_publish_plans` / `post_publish_plan`     | 发布计划；`normal` 类型需至少 1 个子任务（title、channels、contentPrompt） |
| `query_agent_rules` / `post_agent_rule`         | 用户规则；保存后 **下一轮对话** 起注入 system prompt                     |


示例：「帮我建一个每天 9 点的任务，用 custom_prompt 汇总 AI 热点，先不要启用。」

### 5.3 聊天执行指令

无需进入对应页面，直接在聊天中发送：


| 格式                        | 动作                             |
| ------------------------- | ------------------------------ |
| `执行定时任务：名称` / `运行定时任务 名称` | 匹配并执行定时任务                      |
| `执行任务：名称` / `运行任务 名称`     | 匹配并运行发布计划                      |
| `执行流程：名称` / `运行流程 名称`     | 匹配并运行工作流（publish 镜像流程请用「执行任务」） |




### 5.4 发一条小红书（推荐路径）

1. 点击 **+ 新任务**。
2. 输入例如：
  > 帮我发一条小红书，内容关于今日 A 股收盘速读，标题不超过 20 字。请从相关新闻网页抓取配图后发布。
3. Agent 会优先调用 `fetch_web_images` 从来源页下载配图。
4. **本地上传为可选**：需要指定某张图时，再点输入框旁回形针选择图片。
5. 右侧会打开 **智能体浏览器**，进入创作台；未登录时按提示扫码后点 **继续**。
6. 非「完全访问」模式下，正式点「发布」前会再次确认。



### 5.5 配图优先级

1. `imagePaths` / `fetch_web_images` 下载的本地文件
2. `imageSourceUrl` / `imageUrls`（工具内自动下载）
3. 用户本轮上传的附件（可选）



### 5.6 聊天界面功能


| 功能          | 说明                                 |
| ----------- | ---------------------------------- |
| 流式 Markdown | 实时渲染 Agent 回复                      |
| 思考过程        | 独立折叠区展示推理（受思考模式开关控制）               |
| 工具调用        | 折叠展示工具参数与结果                        |
| 代码块         | 超过 12 行默认折叠，支持语法高亮                 |
| HTML 预览     | 生成的 HTML 可在聊天内 iframe 预览，或「在浏览器打开」 |
| K 线图表       | A 股分析结果内嵌 ECharts 图表               |
| 工具进度        | Remotion 渲染等长耗时操作展示进度条             |
| 产物操作        | 打开文件所在目录（访达/资源管理器）、浏览器打开 HTML      |
| 任务清单        | 浮动清单跟踪步骤；完成后可「总结为技能」               |
| 智能体浏览器      | 顶栏地球图标开关右侧截帧预览                     |
| 附件上传        | 输入框回形针；vision 能力可识图                |




### 5.7 权限说明


| 模式      | 行为                            |
| ------- | ----------------------------- |
| 需确认（默认） | 登录、正式发布、Remotion 渲染等敏感操作前暂停等人 |
| 完全访问    | 跳过部分确认（仍建议人工看一眼发布结果）          |

## 6. AI 视频与 Remotion



### AI 叙事视频管线

适合「一句话生成视频」类任务。Agent 依次调用：

1. `generate_script` — 生成剧本
2. `generate_storyboard` — 生成分镜
3. `generate_scene_assets` — 生成场景素材（图/视频/配音）
4. `compose_video` — 合成成片

成片保存在 `videos/` 目录，可在 **设置 → 资产** 中预览。

### Remotion 程序化视频

适合精确动效、字幕、数据可视化、品牌模板类视频。**推荐优先使用内置/自建模板**，再预览与渲染；无合适模板时再从零写代码。

#### 模板优先（推荐）

1. 在聊天中说明需求（如「黑金竖版片头，标题月社」），或让 Agent 调用 `query_remotion_templates` 查看列表。
2. `remotion_apply_template` — 将会话工程挂载为指定模板（内置示例：`brand-intro` 竖版片头、`karaoke-captions` 横版字幕）。
3. `remotion_studio`（可选）— 在浏览器打开 Remotion Studio；若模板带 schema，可在右侧 **Props** 面板调文案、主题、字号等。
4. 若在 Studio 里改过参数，让 Agent 执行 `remotion_update_input_props` 写入工程，**再渲染**，保证成片与预览一致。
5. `remotion_render` — 导出 mp4（渲染前需确认，界面展示渲染进度）。

#### 从零编写（定制）

1. `remotion_init_project` — 初始化 React 视频工程（复制内置 starter）。
2. `write_file` — 编写 `src/ActiveTemplate.tsx` 或相关组件。
3. `remotion_studio` → `remotion_update_input_props`（若需固定参数）→ `remotion_render`。

#### 模板从哪里来

| 来源 | 说明 |
|------|------|
| **内置** | 仓库 `resources/remotion/templates/`，随应用打包 |
| **技能市场 → 视频模板** | （已迁至侧栏独立页）列表浏览、从 GitHub URL 导入、删除本地模板 |
| **侧栏「视频模板」** | 详情、编辑 meta/defaultProps、复制内置为可编辑副本、打开目录 |
| **聊天成片** | Remotion 会话导出的 mp4 旁点 **存为 Remotion 模板** |
| **技能附属** | 技能目录下 `remotion-templates/` 子目录，安装技能时自动注册 |
| **Agent** | `remotion_save_template` 将当前会话工程快照存为模板 |

导入 GitHub 仓库时，目录需包含 `meta.json` + `Composition.tsx`，或根目录 `manifest.json` 索引多个子模板。

首次使用 Remotion 渲染前请执行 `pnpm install:remotion-browser`。

## 7. 发布工作台

1. 侧栏进入 **发布**。
2. 可点 **导入示例** 得到多渠道示例子任务。
3. 编辑子任务的主题与内容说明，或选择串联流程模式。
4. 点 **运行**：会新建主聊天会话，由 Agent **串行**执行子任务。
5. 执行进度请在主聊天窗口与任务清单中查看。

也可在聊天中用 `post_publish_plan` 创建计划（含子任务），保存后本页列表会自动更新。

---



## 8. 流程编排

1. 侧栏进入 **流程**。
2. 新建工作流，在可视化画布中拖拽节点（Agent、工具、通知、条件、并行、输入/输出等）。
3. 保存后点击 **运行** 立即执行。
4. 也可在定时任务或发布计划中关联流程。

---



## 9. 定时任务

1. 侧栏进入 **定时任务**，或在聊天中用 `post_scheduled_task` 创建。
2. 点击 **新建任务**，配置：
  - **重复规则**：单次 / 每天 / 每周
  - **执行时间**：具体时刻或星期几
  - **动作类型**：发布计划 / 自定义指令 / 流程
  - **通知渠道**（可选）：执行完成后推送消息
3. 保存后由主进程每 30 秒轮询调度。
4. 可点击 **立即执行** 手动触发；执行记录会关联到对应聊天会话。

## 10. 技能市场与规则



### 技能市场

1. 侧栏进入 **技能市场**。
2. 浏览内置技能（小红书发布、Remotion 套件、AI 视频等）。
3. 顶部 Tab：**全部 / 活跃 / 已归档 / 市场 / 我的**。
4. Remotion 视频模板请到侧栏 **视频模板** 页维护。
5. 启用/禁用技能；支持 **从模板安装**、**从链接导入**、**手动新建/编辑**。
6. 任务完成后可在任务清单点 **总结为技能**，将成功步骤保存为新技能。
7. 已启用技能的摘要注入 Agent 系统提示；运行时 `use_skill` 按需加载完整内容。



### 规则

1. 侧栏进入 **规则**。
2. 管理 MDC 规则文件（如「简体中文回复」默认规则）。
3. 启用后注入各角色 system prompt。
4. 也可在聊天中用 `post_agent_rule` 新增或更新规则（下轮对话起生效）。

## 13. 本地数据目录

应用数据位于系统 userData 下的 `react-agent-data/`：


| 路径                          | 内容                    |
| --------------------------- | --------------------- |
| `settings.json`             | API Key、多模型连接、角色映射、权限 |
| `sessions/`                 | 聊天会话                  |
| `publish-plans/`            | 发布计划                  |
| `scheduled-tasks/`          | 定时任务                  |
| `workflows.json`            | 流程定义                  |
| `workflow-runs.json`        | 流程运行记录                |
| `channels.json`             | 渠道配置                  |
| `skill-states.json`         | 技能启用状态                |
| `browser-profile/`          | 有头浏览器登录 Cookie        |
| `browser-profile-headless/` | 无头抓取专用 Profile        |
| `artifacts/`                | Agent 通用产出            |
| `videos/`                   | 视频成片与分镜素材；Remotion 会话工程在 `videos/remotion/<会话id>/` |
| `videos/remotion/<会话id>/.remotion-input-props.json` | 当前模板参数（渲染与 Studio 对齐用） |
| `resources/`                | 安装版可写技能/规则副本；用户 Remotion 模板在 `resources/remotion/templates/` |


macOS 典型路径：`~/Library/Application Support/lingxifa/react-agent-data/`

清除登录：**设置 → 渠道状态** → **清除全部发布渠道登录态**。

## 16. 常见问题

**Q: 提示未配置 API Key**  
A: 先到设置页 → 模型与 API 保存 Key。

**Q: 上传控件找不到 / 填不了标题**  
A: 平台 DOM 可能改版。Agent 会回退到 `browser_snapshot` + 原子工具；也可在右侧浏览器手动补全后点继续。

**Q: Chromium 弹窗和右侧预览同时出现？**  
A: 当前为有头 Playwright 便于登录与调试，右侧同步截帧，属预期行为。

**Q: 提示「正在现有的浏览器会话中打开」或 browser has been closed？**  
A: 多为上次异常退出留下的 Profile 锁。应用会在启动浏览器前自动清理 `SingletonLock`；请重启 `pnpm dev` 后重试。若仍失败，可到设置页清除发布渠道登录态。

**Q: Remotion 渲染失败或缺少浏览器？**  
A: 执行 `pnpm install:remotion-browser` 安装 Remotion 渲染依赖。

**Q: Studio 里调了参数，成片和预览不一致？**  
A: 调参后需让 Agent 执行 `remotion_update_input_props`（或你在确认渲染前说明「按当前参数渲染」），再 `remotion_render`。渲染读取的是工程内 `.remotion-input-props.json`，不是 Studio 内存状态。

**Q: 如何管理 / 导入 Remotion 模板？**  
A: 侧栏进入 **视频模板**：浏览内置与用户模板、编辑参数、从 GitHub URL 导入、复制内置为可编辑副本、删除本地模板。聊天里 Remotion 成片可点 **存为 Remotion 模板**。

**Q: 如何在聊天里直接执行任务？**  
A: 发送「执行定时任务：xxx」「执行任务：xxx」或「执行流程：xxx」，名称需与列表中的任务/计划/流程名称匹配。

**Q: 如何在聊天里创建定时任务 / 发布计划 / 规则？**  
A: 用自然语言说明需求，或点欢迎页对应快捷卡。Agent 会调用 `post_scheduled_task` / `post_publish_plan` / `post_agent_rule` 落盘；定时任务新建默认未启用，规则从下一轮对话起生效。侧栏列表会自动刷新。

**Q: 文档放哪？**  
A: 项目文档统一放在本仓库 `[doc/](./)` 目录：使用手册、项目架构等；概览见根目录 [README.md](../README.md)。
